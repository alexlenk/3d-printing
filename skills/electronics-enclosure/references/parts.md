# Measured / researched parts

The part data lives in the component library, one file per part, with the source of every
number and a ready `spec.json` snippet:

- In the repository: `components/` at the repo root (index: `components/README.md`).
- In the packaged skill (.skill / zip): `references/components/` next to this file.

Always compare with the user's actual board (photo) - batches and clones differ. When you
measure or research a new part for a design, add it to the library using
`components/_template.md`, so the next box starts from it.
