# Disc magnet Ø4 x 2 mm (N52)

**Status:** printed (press-fit from below, flush)

| What | Value |
|---|---|
| Pull on steel | ~0.3-0.4 kg each (typical) |
| Press-fit pocket | Ø4.1 x 2.0, from the bottom, flush |
| Plastic above the magnet | >= 1.2 mm (thicken the floor or add a Ø8 boss) |
| Pocket mouth | 0.4 mm x 45° chamfer helps against elephant foot |

Four in the corners for a box; two on the centre line for something small and light.
Keep >= 10 mm from antennas.
